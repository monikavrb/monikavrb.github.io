# Welcome
Another tool to learn Chinese, adding flash card from 1-5

The site root (`index.html`) is a landing page where you pick a language. The HSK flashcard app lives in [`hsk-flash-card/`](hsk-flash-card/). Japanese (Minna no Nihongo) is coming soon.

Access here: https://monikavrb.github.io/hsk-flash-cards/

If you click the speaker button and the voice stays silent here are some steps:

Windows: Settings → Time & language → Language & region → add Chinese (Simplified), and include its speech pack.
Android: Settings → System → Languages → Text-to-speech output → install Chinese voice data in the Google engine.
iPhone/Mac: Settings → Accessibility → Spoken Content → Voices → Chinese, and download one.

Work best using Chrome, Edge, and Safari :)
